# Linde TDG Log — Android app

Downloads of the Linde TDG Log app for Android. This repository holds only the app files (APK), no source code.

- **Latest version:** [Releases](https://github.com/jackatwinnipeg/tdg-log-app/releases/latest)
- The app checks this page itself and offers new versions under **More → Version**.
- Sign-in with a Driver Number is required; the app shows no data without it.
